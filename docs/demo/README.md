# Видеодемонстрация Напарника

Черновик реального UI-прогона для проверки перед сдачей.

- [Видео MP4, 4:24, 1600×1080, 25 fps, около 11 MB](naparnik-demo.mp4)
- [Подробный режиссёрский сценарий](scenario.md)
- [Разбор требований PDF, результаты и известный недочёт](review.md)
- [Кадр из ролика](preview.png)

Видео без звука, с поясняющими титрами. Корпоративные сервисы имитируются, данные синтетические. Паузы между эпизодами сокращены; ответы и статусы не подменялись. Известное ограничение указано в отчёте и финальном титре.
